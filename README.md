# KINGDON

## Kingdom Works prototype

A small original web 3D RPG/territory-management prototype built with plain HTML, CSS, JavaScript, and Three.js.

### Play

Open `index.html` in a browser, or serve the folder with a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

### Controls

- **WASD / Arrow keys:** move
- **Space:** attack
- **E:** gather resources or place the selected building
- **Mobile:** drag the virtual joystick to move; use **E** and **sword** buttons to interact and attack

### Current features

- 3D moving character
- Keyboard and touch controls
- Real-time enemy pursuit and combat
- Gatherable trees and rocks
- Gold, wood, and stone economy
- House, watchtower, and workshop construction
- Small estate area and expanded outdoor terrain
